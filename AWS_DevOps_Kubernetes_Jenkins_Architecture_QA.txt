
AWS + DEVOPS + KUBERNETES + JENKINS ARCHITECTURE (INTERVIEW Q&A)
===============================================================

Q1. Explain a typical AWS DevOps architecture.
A. Code is stored in GitHub, Jenkins triggers CI/CD, Docker builds images, images are pushed to ECR,
deployed on EKS or EC2 behind ALB, Auto Scaling handles load, CloudWatch monitors everything.

Q2. How does Jenkins fit into DevOps architecture?
A. Jenkins automates build, test, Docker image creation, and deployment.

Q3. Explain Kubernetes architecture.
A. Kubernetes has a control plane (API Server, Scheduler, Controller Manager, etcd)
and worker nodes (kubelet, kube-proxy, containers).

Q4. How traffic flows in Kubernetes?
A. User → Load Balancer → Service → Pod.

Q5. Why use EKS instead of self-managed Kubernetes?
A. AWS manages control plane, improves security and reliability.

Q6. How do you handle secrets in DevOps architecture?
A. Using Kubernetes Secrets, Jenkins credentials, AWS Secrets Manager.
